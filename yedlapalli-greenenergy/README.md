# Yedlapalli Greenenergy – 3-page corporate website

A responsive static website starter built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript.

## Pages
- `index.html` – Home
- `about.html` – About & Capabilities
- `sustainability.html` – Sustainability & Contact

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
1. Replace the text-based Y brand mark with the client's approved logo.
2. Confirm company address, official phone, email, project site and social links.
3. Obtain written approval for every DPR figure and project status statement.
4. Confirm the discrepancy between the outline's 1.2 GW wafer capacity and page 5's 1.0 GW saleable output; confirm investment and BESS wording too.
5. Configure a real enquiry recipient or connect the form to a trusted form-processing endpoint. The current form is deliberately a non-sending demo until an official email is supplied.
6. Replace stock image URLs with client-approved/licensed project and factory photographs where available.
7. Check the Hostinger hosting plan and upload the website files to the hosting document root (commonly `public_html`).

## Notes
- The website consistently describes the facility as proposed/planned, because the supplied DPR is a greenfield project report and does not establish that the facility is operational.
- Bootstrap and Google Fonts are loaded from CDNs, so internet access is required for those resources.
